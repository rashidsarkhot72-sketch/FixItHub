\# 🏢 FixItHub - AWS Maintenance Request System



FixItHub is an AWS-based apartment maintenance and complaint tracking system.



\## 🚀 Features



\* Create maintenance complaints

\* Automatic Ticket ID generation

\* Automatic complaint tracking

\* Maintenance category selection

\* Urgent complaint option

\* Photo upload

\* Booking date and time

\* Resident availability

\* Admin complaint management

\* Complaint status tracking

\* Admin remarks



\## ☁️ AWS Services



\* Amazon API Gateway

\* AWS Lambda

\* Amazon S3

\* Amazon DynamoDB

\* IAM

\* Amazon CloudWatch
